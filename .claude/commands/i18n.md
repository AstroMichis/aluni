# /i18n -- Internationalization Compliance

You are adding or auditing i18n for Aluni. The request is: $ARGUMENTS

## Before starting:

1. Read `docs/I18N.md`
2. Read `config/locales/en/en.yml` and the relevant `config/locales/en/views/en.<area>.yml`
3. Read the matching `es` files

## File structure

```
config/locales/
  en/
    en.yml                 # app_name, meta, layouts, native_only, signups, platform, service_errors, passkeys.errors, formats
    en.activerecord.yml    # model and attribute names
    views/en.<area>.yml    # one file per view area (pages, sessions, registrations, passkeys, app, shared, native_app)
    mailers/               # one file per mailer
  es/                      # same tree, same keys
```

## Rules

- English is the source; Spanish is written in the same change, same keys. The parity spec fails on any difference.
- Keys nest under the view path; use lazy lookup in views and controllers (`t(".title")`).
- Shared UI words go under `shared.*`; flash messages under the controller's action key (`sessions.destroy.signed_out`).
- Every visible text uses `t()`: headings, paragraphs, labels, buttons, links, `placeholder`, `title`, `aria-label`, empty states, confirmations, error messages. `spec/i18n/core_copy_rules_spec.rb` scans views for text outside `t()`.
- Dates `l(time, format: :short)` / `l(date, format: :long)`; currency formats are USD in both locales; pluralization with `one:`/`other:`; interpolation `%{name}`.
- No em dashes. Spanish uses neutral `tú` forms, no regional voseo. Short sentences; the audience may not be comfortable with technology.
- Never quote-less `on/off/yes/no/true/false/null` keys (`spec/i18n/no_boolean_keys_spec.rb`).

## Creating entries

```yaml
# config/locales/en/views/en.things.yml
en:
  app:
    things:
      index:
        title: "Your things"
        empty: "Nothing here yet."
        new: "Add a thing"
```

```yaml
# config/locales/es/views/es.things.yml
es:
  app:
    things:
      index:
        title: "Tus cosas"
        empty: "Todavía no hay nada."
        new: "Agregar una cosa"
```

## Audit mode

1. Hardcoded text in views: run `mise exec -- bundle exec rspec spec/i18n` (the copy rules spec lists offenders with file and line)
2. Hardcoded flash messages: `grep -rn 'notice: "\|alert: "' app/controllers`
3. Missing keys: `raise_on_missing_translations` is on in test, so request specs that render the page fail
4. Parity: `spec/i18n/locale_parity_spec.rb` names the keys present in one locale only
5. Unused keys: compare `grep -rhoE 't\("[a-z_.]+"' app | sort -u` against the locale trees
6. Interpolation: a `%{variable}` without a matching argument raises `I18n::MissingInterpolationArgument` in specs

Report findings by severity and fix English and Spanish together.
